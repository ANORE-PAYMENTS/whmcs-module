# Anore для WHMCS

Платёжный модуль создаёт счёт через Anore, переводит клиента на платёжную форму и автоматически отмечает инвойс WHMCS оплаченным после подписанного вебхука `payment.succeeded`.

## Требования

- WHMCS 8.x;
- PHP 8.1 или новее с расширениями cURL и JSON;
- инвойсы в RUB или USD;
- публичный HTTPS-доступ к callback WHMCS.

## Установка

Скопируйте каталог `modules` из этой папки в корень WHMCS. В результате должны появиться файлы:

```text
modules/gateways/anore.php
modules/gateways/callback/anore.php
```

Откройте `System Settings → Payment Gateways → All Payment Gateways`, активируйте `Anore` и заполните:

- `API URL` — обычно `https://api.anore.cc`;
- `API-ключ` и `Секрет API-ключа` — значения из личного кабинета Anore;
- `Shop ID` — только если используется API-ключ уровня аккаунта;
- `Секрет вебхука` — секрет вебхука выбранного магазина;
- `Методы оплаты` — необязательный список, например `sbp,yoomoney,crypto`.

В настройках этого же магазина Anore укажите URL вебхука:

```text
https://ВАШ-WHMCS/modules/gateways/callback/anore.php
```

Секрет вебхука в Anore и в настройках модуля WHMCS должен полностью совпадать.

## Как работает модуль

Для `orderId` используется ID инвойса WHMCS. Ссылка на уже созданный и ещё действующий платёж сохраняется в таблице `mod_anore_payments`, поэтому обновление страницы инвойса не создаёт дубликаты. Таблица создаётся автоматически при первом платеже.

Callback проверяет `Anore-Signature` как HMAC-SHA256 от исходного JSON, сопоставляет ID, сумму и валюту с созданным модулем платежом, проверяет ID инвойса и ID транзакции стандартными функциями WHMCS и только затем вызывает `addInvoicePayment`. Повторная доставка того же события отвечает `200 OK`, но второй раз деньги не зачисляет.

Событие `payment.expired` записывается в Gateway Log и не меняет инвойс.

## Проверка

1. Создайте тестовый инвойс WHMCS в RUB или USD.
2. Нажмите кнопку оплаты и убедитесь, что открылась платёжная форма Anore.
3. Проведите оплату.
4. Проверьте, что инвойс получил статус `Paid`, а в `Billing → Gateway Log` появилась запись `Successful`.

Тестовый API-ключ Anore не отправляет боевой `payment.succeeded`, поэтому полный callback-сценарий проверяется реальным платежом на минимальную сумму.
